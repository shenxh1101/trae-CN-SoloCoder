## 1. 产品概述
基于 Three.js 的 3D 旋转环状粒子带交互网页，场景中心展示由数千彩色粒子组成的环形粒子带，支持丰富的参数调节、视觉效果切换和配置导入导出，为用户提供沉浸式的 3D 粒子可视化体验。

## 2. 核心功能

### 2.1 功能模块
1. **3D 场景页面**：环形粒子带渲染、交互控制面板、信息显示

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 3D场景页面 | 粒子环渲染 | 数千彩色粒子均匀分布在环上，绕Y轴旋转，带发光材质，颜色沿环渐变 |
| 3D场景页面 | 相机控制 | OrbitControls支持旋转缩放视角，支持自动旋转模式 |
| 3D场景页面 | 参数控制面板 | 环半径、粒子数量(500-5000)、旋转速度、粒子大小、环厚度滑块 |
| 3D场景页面 | 颜色模式切换 | 彩虹渐变、红橙渐变、蓝绿渐变三种模式 |
| 3D场景页面 | 背景切换 | 黑色、深蓝色、星空图片三种背景 |
| 3D场景页面 | 拖尾效果 | 运动时产生拖尾光晕 |
| 3D场景页面 | 连线效果 | 相邻粒子用细线连接形成网状 |
| 3D场景页面 | 中心光球 | 环中心添加发光球体 |
| 3D场景页面 | 截图功能 | 一键截图保存当前画面为PNG |
| 3D场景页面 | 配置导入导出 | 导出环配置为JSON文件，可重新导入加载 |
| 3D场景页面 | 信息显示 | 显示当前粒子数量和帧率(FPS) |

## 3. 核心流程

用户打开页面 → 3D场景自动渲染环形粒子带 → 通过控制面板调节参数实时更新 → 切换视觉效果增强体验 → 截图保存或导出配置


## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色科技感（暗黑底色 + 霓虹色彩粒子）
- 控制面板：半透明毛玻璃风格，悬浮于3D场景右侧
- 字体：Orbitron（标题/数字显示）+ Source Sans 3（控制标签）
- 布局：全屏3D场景 + 右侧浮动控制面板
- 按钮/滑块：圆角霓虹风格，带有微光效果

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 3D场景页面 | 3D渲染区 | 全屏Canvas，占满视口 |
| 3D场景页面 | 控制面板 | 右侧浮动半透明面板，包含滑块、开关、按钮 |
| 3D场景页面 | 信息栏 | 左上角FPS和粒子数量显示 |
| 3D场景页面 | 截图按钮 | 面板底部截图导出按钮 |

### 4.3 响应式
- 桌面优先设计，控制面板在窄屏时可折叠
- Canvas自适应窗口大小

### 4.4 3D场景指导
- 环境：深色背景配合发光粒子营造太空感
- 灯光：环境光 + 点光源，突出粒子发光效果
- 相机：透视相机，默认45度俯视角，OrbitControls交互
- 构图：粒子环居中，相机距离适中保证完整可见
- 后处理：Bloom效果增强粒子发光感
- 性能预算：5000粒子 + 连线需保持60fps
