## 1. 产品概述
AI驱动的闲聊机器人Web应用，支持人物性格设定、情感分析、语音输入和多用户独立会话。用户可通过简洁优雅的Web界面与机器人对话，机器人根据设定的性格（友好、讽刺、专业等）以不同风格回复，并能识别用户情感做出共情回应。

- 目标用户：希望与AI闲聊的普通用户、需要对话式交互体验的开发者
- 核心价值：个性化AI对话体验，兼具趣味性和情感智能

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册，自动分配Session | 与机器人对话、设定性格、上传问答对、使用语音输入 |
| 管理员 | 通过管理入口访问 | 查看所有会话历史、导出CSV |

### 2.2 功能模块
1. **聊天页面**：对话界面、性格设定面板、建议回复按钮、语音输入
2. **管理页面**：会话历史时间线、CSV导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 聊天页面 | 对话区域 | 显示用户与机器人对话消息，支持滚动加载，区分用户/机器人消息样式 |
| 聊天页面 | 性格设定面板 | 下拉选择性格类型（友好、讽刺、专业），实时切换回复风格 |
| 聊天页面 | 建议回复按钮 | 机器人回复后显示3个可能的用户回复选项，点击即可发送 |
| 聊天页面 | 语音输入按钮 | 集成Web Speech API，点击开始录音，语音转文字后发送 |
| 聊天页面 | 问答对上传 | 支持上传JSON格式的自定义问答对，动态扩展知识库 |
| 聊天页面 | 主动话题提示 | 每隔5轮无主题对话时，机器人主动询问用户兴趣 |
| 管理页面 | 会话时间线 | 按时间线展示所有会话的历史记录，支持按会话筛选 |
| 管理页面 | CSV导出 | 将选定会话或全部会话历史导出为CSV文件 |

## 3. 核心流程

用户进入聊天页面 → 系统自动分配Session ID → 用户可选设定机器人性格 → 用户输入消息（文字/语音） → 系统进行情感分析 → 基于问答匹配+性格风格生成回复 → 返回回复及3个建议回复 → 每隔5轮检测是否需要主动发起话题 → 会话历史存储在服务端内存（最近5轮） → 所有对话记录写入本地日志文件

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深墨绿色(#1a2f23) + 翠绿强调色(#4ade80)，营造自然智能感
- 辅助色：暖米色(#f5f0e8)用于背景，金色(#fbbf24)用于高亮
- 按钮风格：圆角胶囊按钮，轻微3D凸起效果，悬停时上浮+阴影加深
- 字体：Noto Sans SC（正文）+ ZCOOL QingKe HuangYou（标题/品牌），中文优先
- 布局风格：左右分栏式，左侧对话区、右侧控制面板；卡片式消息气泡
- 图标风格：线性图标，2px描边，与整体风格统一的翠绿色

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 聊天页面 | 对话区域 | 墨绿渐变背景，用户消息右对齐翠绿气泡，机器人消息左对齐米色气泡，消息间淡入动画 |
| 聊天页面 | 性格设定面板 | 右侧面板，下拉选择器+性格图标预览，切换时有过渡动画 |
| 聊天页面 | 建议回复按钮 | 消息下方横排3个胶囊按钮，淡色背景，悬停变翠绿 |
| 聊天页面 | 语音输入按钮 | 输入框旁麦克风图标按钮，录音时脉冲动画 |
| 聊天页面 | 问答对上传 | 右侧面板文件上传区域，拖拽上传+点击上传 |
| 管理页面 | 会话时间线 | 垂直时间线布局，每个节点展示会话摘要，可展开查看详情 |
| 管理页面 | CSV导出 | 顶部操作栏导出按钮，下拉选择导出范围 |

### 4.3 响应式设计
- 桌面优先设计，大屏左右分栏布局
- 平板：右侧面板折叠为底部抽屉
- 手机：全屏对话，控制面板通过浮动按钮唤起
