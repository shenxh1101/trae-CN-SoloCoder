### ✅ **任务1: 真实覆盖率报告**

**文件**: [coverage.py](file:///Users/mac/code/solo%20coder/258/aitestgen/coverage.py)

**实现的功能**:
1. **`RealCoverageAnalyzer` 类**: 运行真实的 pytest-cov 命令
   ```bash
   python -m pytest tests/ --cov=source --cov-report=json:coverage.json
   ```
2. **JSON报告解析**: 解析 pytest-cov 生成的 JSON 报告，提取：
   - `executed_lines` - 已执行的代码行
   - `missing_lines` - 未覆盖的代码行
   - `executed_branches` - 已覆盖的分支
   - `missing_branches` - 未覆盖的分支
3. **详细报告**: 展示具体哪些代码行和分支未覆盖
4. **多种输出格式**: console、markdown、json、text
5. **向后兼容**: `EstimatedCoverageAnalyzer` 用于预估覆盖率（不运行测试）

**CLI命令**:
```bash
python -m aitestgen.cli coverage examples/calculator.py --run-tests
python -m aitestgen.cli coverage examples/calculator.py --format json --output report.json
```
