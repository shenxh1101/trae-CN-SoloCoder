规则格式说明

JSON 规则格式

{ "id": "C001", "name": "规则名称（简短描述）", "description": "详细的规则说明，解释该规则检测什么风险", "keywords": ["关键词1", "关键词2", "关键词3"], "pattern": "正则表达式（可选，用于复杂匹配）", "severity": "high", "category": "风险分类名称", "suggestion": "针对该风险的具体修改建议措辞", "supported_types": ["all"], "weight": 1.0 } 字段说明： • id: 唯一规则标识，建议格式：C001、C002 等 • name: 规则名称，简洁明了 • description: 详细描述该规则检测的风险类型 • keywords: 关键词数组，包含任意一个即触发 • pattern: 可选，正则表达式进行更精确的匹配 • severity: 风险等级，可选值：high（高）、medium（中）、low（低） • category: 风险分类，如"终止条款"、"责任条款"等 • suggestion: 针对该风险的修改建议 • supported_types: 适用合同类型数组，可选值： - "all": 所有类型 - "employment": 劳动合同 - "lease": 租赁合同 - "nda": 保密协议 - "service": 服务合同 • weight: 规则权重，0.1-2.0，默认为1.0

示例规则 1：检测"甲方有权随时"条款

{ "id": "C001", "name": "甲方单方随时终止条款", "description": "合同中包含甲方有权随时终止合同的表述，对乙方不利", "keywords": ["甲方有权随时", "甲方可随时", "甲方有权单方终止"], "pattern": "", "severity": "high", "category": "终止条款", "suggestion": "建议修改为：双方协商一致可终止合同，或一方需提前30天书面通知对方", "supported_types": ["all"] }

示例规则 2：检测违约金超过30%

{ "id": "C002", "name": "违约金比例过高", "description": "违约金比例超过合同金额的30%，可能被认定为过高", "keywords": ["违约金"], "pattern": "违约金.*(3[1-9]%|[4-9][0-9]%|100%)", "severity": "medium", "category": "违约条款", "suggestion": "建议违约金不超过合同金额的30%，或与实际损失相当", "supported_types": ["all"] }

💡 也可以直接编辑 rules/custom_rules.json 文件批量添加自定义规则。
