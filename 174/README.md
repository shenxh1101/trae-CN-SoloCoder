# 个人预算管理器 (Budget Manager)

一个功能强大的命令行个人财务管理工具，帮助您追踪和管理每月预算。

## 功能特性

### 核心功能
- ✅ **预算设置** - 设定每月各类别（餐饮、交通、娱乐、购物）的预算金额
- ✅ **支出记录** - 每日记录支出，自动扣减对应类别的剩余预算
- ✅ **超支预警** - 80%时黄色提示，100%时红色警告并发出终端响铃
- ✅ **ASCII进度条** - 直观显示本月预算执行情况
- ✅ **多月份管理** - 支持切换月份，查看历史数据

### 高级功能
- ✅ **CSV报表导出** - 导出各月各类别的预算、实际支出和差额
- ✅ **银行CSV导入** - 从银行导出的CSV文件导入支出记录（支持映射规则）
- ✅ **储蓄目标** - 每月自动从总收入中划出固定金额到储蓄类别
- ✅ **预算结转** - 未用完的预算可以结转到下个月
- ✅ **类别分组** - 支持"必要支出"和"可选支出"分组，并统计各自占比

### 使用模式
- ✅ **交互模式** - 菜单驱动的友好界面
- ✅ **单命令模式** - 支持快速命令如 `budget add 餐饮 25.5`

## 安装方法

### 方法一：使用安装脚本（推荐）
```bash
cd /path/to/budget-manager
chmod +x install.sh
./install.sh
```

### 方法二：手动安装
```bash
chmod +x budget.py
sudo ln -s /path/to/budget.py /usr/local/bin/budget
```

### 方法三：直接运行
```bash
python3 budget.py
```

## 快速开始

### 1. 启动交互模式
```bash
budget
# 或
python3 budget.py
```

### 2. 设置本月预算
在交互模式中选择 `3. 设置预算`，或使用命令：
```bash
budget set 餐饮 1000
budget set 交通 500
budget set 娱乐 300
budget set 购物 800
```

### 3. 记录一笔支出
交互模式选择 `2. 记录支出`，或使用快捷命令：
```bash
budget add 餐饮 25.5 午餐
budget add 交通 8.0 地铁
budget add 娱乐 88 电影票
```

### 4. 查看预算状态
```bash
budget status
# 或查看指定月份
budget status 2024-01
```

## 命令详解

### 单命令模式

| 命令 | 说明 | 示例 |
|------|------|------|
| `budget add <类别> <金额> [描述]` | 记录一笔支出 | `budget add 餐饮 35 外卖` |
| `budget status [月份]` | 查看预算状态 | `budget status 2024-01` |
| `budget set <类别> <金额> [月份]` | 设置某类别的预算 | `budget set 交通 500` |
| `budget list [类别] [月份]` | 查看支出明细 | `budget list 餐饮` |
| `budget export [文件名]` | 导出CSV报表 | `budget export report.csv` |
| `budget import <csv文件>` | 导入银行对账单 | `budget import bank.csv` |
| `budget config-import` | 配置导入映射规则 | |
| `budget savings <目标> <收入>` | 设置储蓄目标 | `budget savings 2000 10000` |
| `budget help` | 查看帮助 | |

### 交互模式菜单项

1. **查看预算状态** - 显示本月所有类别的预算执行情况
2. **记录支出** - 添加一笔新的支出记录
3. **设置预算** - 设定或修改某类别的预算金额
4. **查看支出明细** - 列出所有或指定类别的支出记录
5. **切换月份** - 查看历史月份的数据
6. **导出报表 (CSV)** - 导出所有月份的预算报表
7. **导入银行对账单** - 从CSV文件批量导入支出
8. **配置导入映射** - 设置银行CSV的列映射规则
9. **设置储蓄目标** - 配置每月储蓄计划
10. **系统设置** - 启用/禁用预算结转等功能

## 数据存储

所有数据存储在 `~/.budget_manager/` 目录下：

- `budgets.json` - 各月预算设置
- `expenses.json` - 所有支出记录
- `config.json` - 系统配置和类别定义
- `import_mapping.json` - CSV导入映射规则

## 超支预警规则

- **绿色 (0-80%)** - 预算充足
- **黄色 (80-100%)** - 提醒：即将用尽预算
- **红色 (≥100%)** - 警告：已超支！（终端响铃提示）

## 类别分组

默认分组：
- **必要支出**：餐饮、交通
- **可选支出**：娱乐、购物
- **储蓄**：储蓄

可以在 `~/.budget_manager/config.json` 中自定义分组和颜色。

## CSV导入格式

### 配置映射规则
运行 `budget config-import` 来设置：
- 日期列名
- 金额列名
- 类别列名
- 描述列名
- 类别名称映射（银行类别 → 预算类别）

### 示例银行CSV格式
```csv
日期,金额,类别,描述
2024-01-05,35.5,餐饮,麦当劳
2024-01-08,100,购物,超市购物
2024-01-10,15,交通,地铁充值
```

## 预算结转

启用预算结转后，每月未用完的预算将自动添加到下个月的对应类别预算中。

在交互模式中选择 `10. 系统设置` 来启用此功能。

## 储蓄目标

设置储蓄目标后，系统会自动创建一个储蓄类别的预算项，帮助您每月强制储蓄。

```bash
budget savings 2000 10000
```
这表示月收入10000元，每月储蓄目标2000元。

## 示例工作流程

```bash
# 1. 设置本月预算
budget set 餐饮 1000
budget set 交通 500
budget set 娱乐 300
budget set 购物 800

# 2. 记录日常支出
budget add 餐饮 25.5 早餐
budget add 交通 4.0 地铁
budget add 娱乐 50 游戏

# 3. 查看状态
budget status

# 4. 月底导出报表
budget export january_report.csv
```
