```typescript
// 核心功能
```

**关键点**：

- 与 `apiClient` 配合使用

### 3. **src/stores/useEditorStore.ts** - 编辑器状态管理
```typescript
// 核心状态
code: string                  // 当前代码内容
language: Language            // 当前语言 (javascript/python/go/rust)
settings: EditorSettings      // 编辑器设置

// 核心方法
setCode(code)                 // 更新代码
setLanguage(language)         // 切换语言，自动加载对应模板
updateSettings(partial)       // 部分更新设置
resetSettings()               // 重置为默认设置
updateKeybinding(cmd, shortcut) // 更新快捷键

// 持久化配置
仅持久化 settings，不持久化 code 和 language
```

**关键点**：
- 内置 4 种语言的默认代码模板
- 默认主题为 `vs-dark`，支持 `vs-light` 和 `hc-black`
- 内置快捷键配置（保存、运行、格式化等）

---

### 4. **src/stores/useSnippetStore.ts** - 代码片段状态管理
```typescript
// 核心状态
snippets: Snippet[]           // 代码片段列表
currentSnippet: Snippet | null // 当前查看的片段
total: number                 // 总数
page: number                  // 当前页码
hasMore: boolean              // 是否有更多

// 核心方法
fetchSnippets(query?)         // 获取列表（支持搜索、分页）
fetchSnippetById(id)          // 按 ID 获取
fetchSnippetByShortCode(code) // 按短链获取
createSnippet(snippet)        // 创建
updateSnippet(id, snippet)    // 更新
deleteSnippet(id)             // 删除
forkSnippet(id)               // 复刻
likeSnippet(id)               // 点赞（乐观更新）
favoriteSnippet(id)           // 收藏（乐观更新）
```

**关键点**：
- 分页加载：`page > 1` 时追加到列表，否则替换
- 乐观更新：点赞/收藏操作立即更新 UI，不等待 API 响应
- 搜索参数：支持 `SearchQuery` 类型（关键词、语言、排序、分页）

### 5. **src/lib/apiClient.ts** - Axios API 客户端
```typescript
// 配置
baseURL: '/api'               // 通过 Vite 代理转发
timeout: 30000                // 30秒超时
Content-Type: application/json

// 请求拦截器
- 自动从 useAuthStore 获取 token
- 自动注入 Authorization: Bearer {token}

// 响应拦截器
- 401 未授权时自动调用 logout() 登出
```

**关键点**：
- 使用 `useAuthStore.getState()` 直接获取状态，避免 React 组件依赖

### 1. **api/lib/prisma.ts** - Prisma 客户端初始化
```typescript
// 核心逻辑：单例模式，避免开发环境热重载时创建多个连接
const globalForPrisma = globalThis as unknown as { prisma: PrismaClient | undefined }

export const prisma = globalForPrisma.prisma ?? new PrismaClient({
  log: process.env.NODE_ENV === 'development' ? ['query', 'error', 'warn'] : ['error'],
})

if (process.env.NODE_ENV !== 'production') {
  globalForPrisma.prisma = prisma
}
```

### 2. **api/middleware/auth.ts** - JWT 认证中间件
- **导出类型**：`AuthRequest`（扩展 Request 包含 user 信息）、`JwtPayload`
- **核心函数**：
  - `generateToken()` - 生成 JWT Token，有效期 7 天
  - `verifyToken()` - 验证 Token 有效性
  - `auth()` - 强制认证中间件，失败返回 401
  - `optionalAuth()` - 可选认证中间件，未登录也继续

### 3. **api/services/CodeRunnerService.ts** - Docker 代码运行引擎
这是最核心的服务，特点：
- **支持语言**：JavaScript (Node.js 20)、Python (3.12)、Go (1.22)、Rust (1.77)
- **资源限制**：CPU 1核、内存 256MB、超时 10秒
- **安全机制**：禁用网络、只读根文件系统、限制进程数 64、tmpfs 挂载 /tmp
- **stdin 支持**：通过 `PassThrough` 流实现标准输入
- **编译型语言处理**：Go/Rust 先编译再运行，分容器执行
- **自动拉取镜像**：首次运行自动 pull Docker 镜像

```typescript
// 关键配置
const languageConfigs: Record<Language, LanguageConfig> = {
  javascript: { image: 'node:20-alpine', extension: 'js', runCommand: ['node', '/code/main.js'] },

  go: { image: 'golang:1.22-alpine', extension: 'go', compileCommand: ['go', 'build', ...], runCommand: ['/code/main'] },
  rust: { image: 'rust:1.77-alpine', extension: 'rs', compileCommand: ['rustc', '-O', ...], runCommand: ['/code/main'] },
}
```

```typescript
// 快捷键录制
const handleShortcutKeyDown = useCallback((e: React.KeyboardEvent, command: string) => {
  e.preventDefault();
  const keys: string[] = [];
  if (e.ctrlKey || e.metaKey) keys.push('Ctrl');
  if (e.shiftKey) keys.push('Shift');
  if (e.altKey) keys.push('Alt');
  const keyName = e.key === ' ' ? 'Space' : e.key;
  if (keyName !== 'Control' && keyName !== 'Shift' && keyName !== 'Alt' && keyName !== 'Meta') {
    keys.push(keyName.length === 1 ? keyName.toUpperCase() : keyName);
  }
  if (keys.length >= 2) {
    const shortcut = keys.join('+');
    updateKeybinding(command, shortcut);
  }
}, [updateKeybinding]);
```
