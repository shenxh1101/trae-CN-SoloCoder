# 🎙️ AI 播客选题生成器

基于大语言模型的智能播客策划工具，帮助播客创作者快速生成高质量选题方案。

## ✨ 功能特性

- **智能选题生成**: 根据播客定位、目标听众和热点关键词，AI自动生成10个选题方案
- **完整选题信息**: 每个选题包含标题、讨论大纲、嘉宾类型建议、预估时长
- **用户反馈学习**: 支持喜欢/不喜欢标记，系统根据反馈持续优化推荐
- **多格式输出**: 支持导出为Markdown表格或JSON格式
- **批量生成对比**: 同时生成多套不同定位的方案，自动输出对比报告
- **历史风格学习**: 从历史高播放量选题中学习用户偏好的内容风格
- **时效性预测**: 基于热点分析，推荐最佳播出时间窗口
- **任务拆解**: 自动生成选题待办任务清单（联系嘉宾、查资料、录制等）
- **Shownotes导出**: 一键生成播客Shownotes草稿
- **交互式界面**: 命令行交互式操作，实时调整参数

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 文件，填入你的 OpenAI API Key
```

### 3. 运行程序

**交互式模式（推荐）**:
```bash
python cli.py
# 或
python cli.py -i
```

**命令行模式**:
```bash
python cli.py -p "科技趋势访谈" -a "程序员、产品经理" -k "大模型、AI Agent" -f md -o topics.md
```

## 📖 使用说明

### 交互式模式

进入主菜单后，可以选择：

1. **生成选题（交互式）** - 输入播客信息生成选题
2. **批量生成并对比** - 生成多套方案并对比评分
3. **从历史选题学习风格** - 导入历史高播放量选题
4. **查看反馈统计** - 查看用户反馈数据

生成选题后，还可以进行以下操作：
- 标记喜欢/不喜欢
- 生成播出时间窗口
- 生成任务清单
- 导出各种格式文件

### 命令行参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `-p, --position` | 播客定位 | "科技趋势访谈" |
| `-a, --audience` | 目标听众 | "程序员、产品经理" |
| `-k, --keywords` | 热点关键词 | "大模型、AI Agent" |
| `-n, --count` | 生成数量 | 10 |
| `-f, --format` | 输出格式 | md/json/shownotes |
| `-o, --output` | 输出文件 | topics.md |
| `-i, --interactive` | 交互式模式 | - |

### 从历史选题学习

准备一个JSON文件，包含历史高播放量选题数据：

```json
[
  {
    "title": "选题标题",
    "outline": ["要点1", "要点2", "要点3"],
    "guest_type": "嘉宾类型",
    "duration": "预估时长"
  }
]
```

示例文件: [examples/history_topics.json](examples/history_topics.json)

## 💡 使用技巧

1. **关键词要具体**: 输入具体的热点关键词能获得更好的选题
2. **累积反馈**: 多标记喜欢/不喜欢，5次后系统自动学习风格
3. **批量对比**: 不确定定位时，生成2-3套方案做对比
4. **导入历史**: 有历史数据时一定要导入，生成质量会显著提升

## 🔧 配置说明

在 `.env` 文件中可以配置：

```
OPENAI_API_KEY=your_api_key_here
OPENAI_API_BASE=https://api.openai.com/v1
OPENAI_MODEL=gpt-3.5-turbo
```

支持兼容OpenAI协议的其他LLM服务。
