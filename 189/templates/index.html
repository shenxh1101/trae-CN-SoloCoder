将 Markdown 文本转换为 HTML

请求体 (JSON): { "markdown": "# Hello World\n\n这是一段 Markdown 文本", "code_theme": "monokai", "generate_toc": true, "custom_css": "" } 响应 (JSON): { "html": "<!DOCTYPE html>...", "html_body": "<h1>Hello World</h1>...", "toc": "<div class='toc'>...</div>" } 使用示例 (curl): curl -X POST http://localhost:5000/api/convert \ -H "Content-Type: application/json" \ -d '{ "markdown": "# Hello\n\n- 列表项 1\n- 列表项 2", "code_theme": "monokai", "generate_toc": true }'
