# 团队知识库 + 任务看板系统

一个轻量级的团队协作工具，集成文档管理和任务看板功能，专为小型创业团队设计。

## 技术栈

- **前端**: React 18 + 自定义路由（无需构建工具）
- **后端**: Express.js
- **数据库**: better-sqlite3
- **样式**: 纯 CSS

## 功能特性

### 📄 文档库模块
- 文档分类管理（创建/删除分类）
- 文档 CRUD 操作（创建/编辑/删除）
- 支持 Markdown 格式内容
- 按标题搜索文档
- 记录最后修改时间和修改人
- 删除分类时检查是否有文档

### 🎯 任务看板模块
- 三列看板布局（待处理/进行中/已完成）
- 拖拽任务改变状态
- 任务优先级标记（高/中/低）
- 任务指派人、截止日期
- 按指派人筛选
- 任务完成后不可编辑
- 逾期任务高亮显示
- 统计栏显示任务总数、已完成数、逾期数

### 🔗 文档与任务关联
- 文档详情页可关联多个任务
- 任务详情页显示关联文档
- 双向跳转支持
- 多对多数据库关联表

### 📊 活动日志
- 记录所有关键操作（创建/编辑/删除/移动/关联）
- 侧边栏显示最近 20 条动态
- 支持点击跳转到对应文档或任务
- 自动刷新（每 10 秒）

### 📈 仪表盘
- 文档总数、任务总数统计
- 任务完成率环形进度条
- 近 7 天新增任务柱状图
- 逾期任务列表（最多 5 条）
- 最近更新文档（3 篇）

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务器

```bash
npm start
```

服务器将在 `http://localhost:3000` 启动。

### 3. 访问应用

在浏览器中打开 `http://localhost:3000` 即可使用。

## API 接口

### 分类管理
- `GET /api/categories` - 获取所有分类
- `POST /api/categories` - 创建分类
- `DELETE /api/categories/:id` - 删除分类

### 文档管理
- `GET /api/documents` - 获取文档列表（支持 category_id 和 search 参数）
- `GET /api/documents/:id` - 获取文档详情及关联任务
- `POST /api/documents` - 创建文档
- `PUT /api/documents/:id` - 更新文档
- `DELETE /api/documents/:id` - 删除文档

### 任务管理
- `GET /api/tasks` - 获取任务列表（支持 status 和 assignee 参数）
- `GET /api/tasks/:id` - 获取任务详情及关联文档
- `POST /api/tasks` - 创建任务
- `PUT /api/tasks/:id` - 更新任务
- `DELETE /api/tasks/:id` - 删除任务

### 文档任务关联
- `POST /api/documents/:id/tasks` - 关联任务
- `DELETE /api/documents/:id/tasks/:taskId` - 取消关联

### 活动日志
- `GET /api/activity-logs` - 获取活动日志（limit 参数控制数量）

### 仪表盘
- `GET /api/dashboard/stats` - 获取统计数据

## 数据库表结构

- `categories` - 文档分类
- `documents` - 文档
- `tasks` - 任务
- `document_tasks` - 文档任务关联表
- `activity_logs` - 活动日志

## 使用说明

1. **设置用户名**: 点击左侧边栏的用户头像，设置您的用户名，用于记录操作人
2. **文档库**: 点击"文档库"进入文档管理，先选择分类，然后可以创建、编辑、删除文档
3. **任务看板**: 点击"任务看板"进入看板视图，可以拖拽任务卡片改变状态
4. **关联任务**: 在文档详情页可以关联现有任务，双向跳转
5. **查看动态**: 左侧边栏"近期动态"实时显示团队操作记录

## 注意事项

- 数据库文件 `data.db` 会自动创建在项目根目录
- 所有数据持久化存储，重启服务器不会丢失
- 用户名存储在浏览器 localStorage 中
- 无需构建工具，直接运行即可使用
