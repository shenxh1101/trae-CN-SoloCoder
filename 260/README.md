# AI 个人日记分析工具

一个基于Python的命令行AI个人日常反思日记分析工具。

## 功能特性

### 📊 情绪分析
- 自动分析每篇日记的情绪分数 (0-1)
- 生成月度/年度情绪趋势图 (ASCII图表)
- 情绪日历可视化

### 🔍 关键词分析
- 提取高频词汇
- 分析关注点变化
- 检测重复出现的负面模式

### 💬 智能问答
- 支持自然语言提问，如"我什么时候提到过跑步？"
- 关键词搜索并显示上下文
- 统计词频和出现次数

### 📈 成长报告
- 个人成长分析报告
- 月度/年度总结报告
- 正向变化识别
- 改进建议

### 📤 数据导出
- 导出为JSON格式
- 支持匿名化处理（隐藏个人信息）
- 导出情绪数据和关键词频率

### ⚡ 实用功能
- **提醒功能**: 连续3天未写日记自动提醒
- **关键词高亮**: 终端显示时高亮积极/消极词汇
- **天气关联**: 关联天气日志分析情绪影响
- **今日推荐**: 基于历史成功经验生成行动建议

## 安装依赖

```bash
pip install -r requirements.txt
```

**可选依赖（推荐）**:
- `snownlp`: 更准确的中文情绪分析
- `jieba`: 更好的中文分词

## 使用方法

### 启动程序

```bash
python3 main.py
```

首次运行会自动创建示例日记，位于 `diaries/` 目录下。

### 添加日记

在 `diaries/` 目录下创建文本文件，命名格式为 `YYYY-MM-DD.txt`，例如:
- `2024-01-01.txt`
- `2024-12-25.txt`

文件内容就是当天的反思日记，纯文本即可。

### 主菜单

```
1. 查看月度情绪趋势图
2. 查看年度情绪趋势图
3. 查看本月高频词汇
4. 搜索日记内容 / 提问
5. 生成个人成长报告
6. 生成月度报告
7. 生成年度报告
8. 导出数据 (匿名化)
9. 查看今日推荐行动
10. 查看日记列表
11. 查看具体日记内容
0. 退出
```

### 问答示例

**提问方式:**
- "我什么时候提到过跑步？"
- "我提到工作多少次？"
- "哪些日记提到了旅行？"

程序会自动识别问题类型并给出答案。

### 天气日志

在项目根目录创建 `weather_log.json` 文件，格式如下:

```json
{
  "2024-01-01": {
    "weather": "晴",
    "temperature": 20,
    "humidity": 60,
    "notes": "阳光明媚"
  },
  "2024-01-02": {
    "weather": "多云",
    "temperature": 18,
    "humidity": 70,
    "notes": ""
  }
}
```

程序会自动分析天气与情绪的关联。

## 情绪分类标准

- 😊 **积极**: 分数 > 0.7
- 🙂 **中性偏积极**: 0.5 - 0.7
- 😐 **中性偏消极**: 0.3 - 0.5
- 😢 **消极**: 分数 < 0.3

## 关注领域分类

- 工作压力
- 健康生活
- 人际关系
- 个人成长
- 财务状况
- 休闲娱乐

## 自定义配置

编辑 `config.py` 文件可以:
- 修改积极/消极词汇列表
- 调整关注领域关键词
- 修改图表尺寸
- 调整提醒天数

## 注意事项

1. 所有日记文件请使用 UTF-8 编码保存
2. 建议每天写日记以获得更准确的分析结果
3. 数据导出时选择匿名化可保护隐私
4. 本工具所有数据保存在本地，不会上传到服务器
