# 文件夹加密打包工具 - Folder Encryptor

## 功能特性

- ✅ AES-256 加密，使用 GCM 模式
- ✅ RSA 非对称加密支持（公钥加密，私钥解密）
- ✅ 分卷加密打包
- ✅ 文件名加密
- ✅ SHA256 完整性校验
- ✅ 批量加密
- ✅ 加密进度显示
- ✅ 从文本文件读取文件夹列表
- ✅ 加密后自动删除原始文件夹
- ✅ 生成自解压脚本
- ✅ 命令行交互模式和静默模式
- ✅ 加密注释
- ✅ SFTP 上传

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 基本加密（密码模式）

```bash
# 交互模式
python folder_encryptor.py encrypt -i /path/to/folder

# 静默模式（指定密码）
python folder_encryptor.py encrypt -i /path/to/folder -p mypassword -o output.enc
```

### 2. 解密

```bash
# 交互模式
python folder_encryptor.py decrypt -i /path/to/file.enc

# 静默模式
python folder_encryptor.py decrypt -i /path/to/file.enc -p mypassword -o /output/dir
```

### 3. RSA 加密模式

```bash
# 生成密钥对
python folder_encryptor.py genkey -o ./keys

# 使用公钥加密
python folder_encryptor.py encrypt -i /path/to/folder --public-key ./keys/public_key.pem

# 使用私钥解密
python folder_encryptor.py decrypt -i /path/to/file.enc --private-key ./keys/private_key.pem
```

### 4. 分卷加密

```bash
# 分割成 10MB 大小的分卷
python folder_encryptor.py encrypt -i /path/to/folder --volume-size 10485760

# 解密分卷（支持通配符）
python folder_encryptor.py decrypt -i "/path/to/*.part*.enc"
```

### 5. 加密文件名

```bash
python folder_encryptor.py encrypt -i /path/to/folder --encrypt-filenames
```

### 6. 批量加密

```bash
# 从文件读取文件夹列表
python folder_encryptor.py batch --folder-list folders.txt -o ./encrypted

# 单个文件夹批量模式
python folder_encryptor.py batch -i /path/to/folder -o ./encrypted
```

### 7. 生成自解压脚本

```bash
python folder_encryptor.py encrypt -i /path/to/folder --self-extracting extract.py
```

### 8. 添加注释

```bash
python folder_encryptor.py encrypt -i /path/to/folder --comment "重要备份文件"
```

### 9. 加密后删除原始文件夹

```bash
python folder_encryptor.py encrypt -i /path/to/folder --delete-original
```

### 10. SFTP 上传

```bash
python folder_encryptor.py encrypt -i /path/to/folder \
    --sftp-host example.com \
    --sftp-port 22 \
    --sftp-user username \
    --sftp-pass password \
    --sftp-path /remote/dir
```

## 文件夹列表文件格式

创建一个文本文件，每行一个文件夹路径，支持 `#` 注释：

```
# 这是注释
/path/to/folder1
/path/to/folder2
/path/to/folder3
```

## 文件格式说明

加密文件格式（.enc）：

```
[魔术头 4字节] + [版本号 2字节] + [密钥方式 3字节] + [盐 16字节]
+ [元数据长度 4字节] + [元数据 JSON] + [加密的AES密钥(可选)]
+ [IV 16字节] + [加密数据] + [认证标签 16字节]
```

## 安全说明

- 使用 AES-256-GCM 加密，提供保密性和完整性
- PBKDF2 密钥派生（100,000 次迭代）
- RSA-2048/4096 非对称加密支持
- 每个文件使用独立的随机盐和 IV

## 示例

```bash
# 完整示例：加密一个文件夹，带注释，加密文件名，分卷5MB，生成自解压
python folder_encryptor.py encrypt \
    -i ./important_data \
    -p mysecurepassword \
    --comment "2024年重要数据备份" \
    --encrypt-filenames \
    --volume-size 5242880 \
    --self-extracting important_data_extract.py
```
