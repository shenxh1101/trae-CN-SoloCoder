### 🎨 三种小组件 UI 尺寸

| 尺寸 | iOS Widget Family | Android 尺寸 | 主要内容 |
|------|------------------|-------------|---------|
| **Small** | systemSmall | 2x2 | 天数 + 事件名称 + 分类标签 |
| **Medium** | systemMedium | 4x2 | 左侧：分类/名称/状态/时分秒；右侧：大字号天数 |
| **Large** | systemLarge | 4x4 | 完整详情：分类/名称/大字号天数/时分秒卡片/目标日期/重复指示器 |

### 🔄 数据同步机制

```
React Native State (Redux)
        ↓ (widgetSyncMiddleware 自动监听)
    WidgetManager.ts
        ↓ (NativeModules 调用)
┌─────────────┬──────────────┐
│ iOS (Swift) │ Android (Kotlin)│
│  App Group  │ SharedPreferences│
│ UserDefaults│                │
└─────────────┴──────────────┘
        ↓ (触发刷新)
  WidgetKit Timeline / AppWidgetManager
        ↓
  桌面/锁屏小组件 UI
```

### 🚀 下一步操作建议

   ```bash
   cd android && ./gradlew clean
   ```
