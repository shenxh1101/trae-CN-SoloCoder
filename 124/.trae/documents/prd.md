## 1. 产品概述

基于 Three.js 的 3D 魔方复原模拟器，提供沉浸式的魔方操作体验。用户可通过鼠标/触摸旋转视角、拖拽层来操作魔方，支持打乱、自动复原、计时、截图等功能。
- 面向魔方爱好者、学习者和休闲用户，提供直观的 3D 魔方操作与复原练习工具
- 核心价值：在浏览器中真实还原魔方操作体验，结合计时和解法展示辅助用户提升复原技能

## 2. 核心功能

### 2.1 用户角色
无需角色区分，所有用户享有同等功能。

### 2.2 功能模块
1. **主页面**：3D 魔方场景、操作控制面板、解法步骤列表、计时器

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 3D 魔方场景 | 中心渲染 3×3 魔方，每面 9 色块；支持鼠标拖拽旋转视角；支持点击拖拽某层旋转；支持触摸操作 |
| 主页面 | 操作控制面板 | 打乱按钮、自动复原按钮、重置按钮；动画速度滑块；贴纸材质切换（经典/荧光/黑白灰）；网格辅助线开关；截图按钮；保存/加载 JSON 按钮 |
| 主页面 | 解法步骤列表 | 记录每次旋转操作（手动/自动）；显示完整旋转序列；自动复原时高亮当前步骤 |
| 主页面 | 计时器 | 打乱后自动开始计时；手动复原后自动停止；显示复原耗时；记录最佳成绩 |

## 3. 核心流程

用户打开页面后，3D 魔方以完成状态呈现。用户可通过以下流程操作：

1. **自由操作**：拖拽旋转视角观察魔方，拖拽某层执行旋转操作
2. **打乱练习**：点击打乱按钮随机打乱魔方，计时器自动开始
3. **手动复原**：用户逐步操作魔方复原，复原后计时器自动停止
4. **自动复原**：点击自动复原按钮，按预设算法动画展示每步旋转
5. **状态管理**：可截图保存、导出 JSON、从 JSON 恢复

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色科技风背景（#0a0a0f），配合霓虹蓝（#00d4ff）和亮橙（#ff6b2b）强调色
- 按钮风格：圆角微光按钮，hover 时发光效果
- 字体：显示字体使用 Orbitron（科技感），UI 字体使用 Noto Sans SC（中文支持）
- 布局：3D 场景居中占主区域，右侧控制面板，底部步骤列表
- 图标：简约线条图标风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 主页面 | 3D 魔方场景 | 深色背景渐变，环境光+方向光，抗锯齿渲染，地面反射 |
| 主页面 | 操作控制面板 | 半透明玻璃态面板，分组按钮，滑块控件，下拉选择器 |
| 主页面 | 解法步骤列表 | 半透明面板，步骤条目带序号，当前步骤高亮 |
| 主页面 | 计时器 | 顶部居中大字号数字显示，毫秒精度 |

### 4.3 响应式设计
- 桌面优先设计，3D 场景占主区域
- 移动端：控制面板折叠为底部抽屉，3D 场景全屏，支持触摸手势旋转
- 触摸优化：双指旋转视角，单指拖拽层旋转，触摸反馈

### 4.4 3D 场景指引
- 环境：深色渐变背景，微弱环境雾效增加深度感
- 灯光：环境光 + 主方向光 + 填充光，营造魔方立体感
- 相机：透视相机，默认 45° 俯角，支持自由旋转和缩放
- 构图：魔方居中，留有呼吸空间，控制面板不遮挡主视角
- 交互：OrbitControls 旋转视角，自定义射线检测实现层拖拽旋转
- 动画：层旋转使用缓动函数（ease-in-out），速度可调
- 后期处理：可选 SSAO 增强立体感
