## 1. 产品概述

基于 Three.js 的风格化3D地形生成器，用户上传参考图片后，系统自动提取颜色分布并映射到噪声生成的3D地形上，实现"以图定色"的创意地形可视化。面向设计师、游戏开发者及创意爱好者，提供快速生成风格化地形的工具。

- 解决问题：传统地形生成颜色单调，用户难以快速获得与特定风格匹配的地形色彩方案
- 目标用户：3D艺术家、独立游戏开发者、创意编码爱好者、视觉设计师

## 3. 核心流程

1. 用户进入页面，看到默认地形（使用默认色板）
2. 用户上传参考图片 → 系统提取主色分布 → 地形颜色实时更新
3. 用户调节精细度/起伏强度/种子 → 地形实时重新生成
4. 用户调整颜色映射曲线 → 地形颜色实时更新，图例同步变化
5. 用户按需添加水面/天空、开启自动环绕
6. 用户截图/导出OBJ/导出灰度图保存结果

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空黑(#0a0e17) + 星云紫(#8b5cf6) 作为强调色，搭配青蓝渐变
- **次色调**：暗灰色面板(#141926)，半透明玻璃效果控件
- **按钮风格**：圆角胶囊型按钮，带微妙发光边框，hover时边框增亮
- **字体**：标题使用 Orbitron（科技感显示字体），正文使用 Noto Sans SC（清晰中文）
- **布局风格**：左侧3D画布全屏，右侧浮动半透明控制面板，底部工具栏
- **图标风格**：线性描边图标，与科技感UI一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主场景页 | 3D画布区域 | 全屏Three.js渲染，暗色背景，占页面左侧约75% |
| 主场景页 | 控制面板 | 右侧浮动半透明玻璃面板，包含所有滑块/按钮/上传区，可折叠分组 |
| 主场景页 | 参考图上传区 | 拖拽区域+预览缩略图，面板顶部 |
| 主场景页 | 颜色映射曲线 | 小型Canvas编辑器，横轴高度0~1，纵轴颜色偏移 |
| 主场景页 | 颜色映射图例 | 垂直渐变条，标注高度值与对应颜色 |
| 主场景页 | 底部工具栏 | 水平排列的图标按钮：截图、OBJ导出、灰度图导出、自动环绕开关 |

### 4.3 响应式设计

- 桌面优先设计，3D画布占满可用空间
- 平板：控制面板变为底部抽屉
- 移动端：控制面板变为全屏覆盖弹窗，3D画布全屏

### 4.4 3D场景指导

- **环境/氛围**：深空星云风格，暗色雾化远景，营造科幻地形探索感
- **灯光设置**：方向光 + 环境光 + 半球光，方向光投射柔和阴影
- **相机设置**：透视相机，初始俯视30度角，支持OrbitControls手动控制
- **构图与焦点**：地形居中，水面在底部半透明反射
- **交互与动画**：水面微波动动画，天空球缓慢旋转，相机自动环绕
- **后处理效果**：可选辉光效果（Bloom）增强高亮区域
- **性能预算**：地形细分512段时仍保持30fps以上

## 5. 非功能需求

- 地形生成延迟 < 500ms（256段细分时）
- 图片颜色提取延迟 < 200ms
- 支持 JPG/PNG/WebP 格式参考图片上传
- 单页应用，无需后端服务，纯前端实现
