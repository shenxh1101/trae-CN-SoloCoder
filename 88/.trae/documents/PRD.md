## 1. 产品概述
基于Three.js的3D旋转几何体展示网页，提供丰富的交互控制和视觉效果，面向设计师、开发者和3D爱好者。
- 主要用途：交互式展示3D几何体的各种材质、光照、动画和导出功能
- 目标用户：前端开发者、3D设计师、教育工作者、技术爱好者
- 产品价值：一站式3D几何体实验平台，快速预览不同参数对几何体的影响

## 2. 核心功能

### 2.1 用户角色
无需用户角色区分，所有用户拥有完全相同的功能权限。

### 2.2 功能模块
1. **3D场景展示**：几何体渲染、材质、光照、反射
2. **控制面板**：几何体选择、材质调节、动画控制、背景切换
3. **导出功能**：截图PNG、导出OBJ文件
4. **统计信息**：顶点数、面数实时显示
5. **多几何体模式**：2x2网格同时展示4个几何体

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页 | 3D场景画布 | Three.js渲染画布，支持鼠标拖拽旋转视角 |
| 主页 | 几何体控制 | 下拉菜单切换5种几何体（立方体、球体、圆柱体、圆锥体、环面） |
| 主页 | 材质控制 | 动态彩色渐变材质、线框模式开关、金属度/粗糙度滑块、缩放滑块 |
| 主页 | 光照控制 | 环境光开关、点光源开关 |
| 主页 | 动画控制 | 自动旋转、上下浮动、脉冲缩放三种动画模式切换 |
| 主页 | 背景控制 | 纯色、渐变色、星空图三种背景切换 |
| 主页 | 地面反射 | 反射平面开关，显示几何体在地面的倒影 |
| 主页 | 统计面板 | 实时显示当前几何体的顶点数和面数 |
| 主页 | 导出功能 | 一键截图保存为PNG、导出几何体为OBJ文件下载 |
| 主页 | 多几何体模式 | 2x2网格同时显示4个几何体，每个独立控制旋转 |

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色科技感背景（#0a0a0f），配合霓虹蓝紫渐变强调
- 按钮风格：圆角玻璃拟态（glassmorphism），带微妙边框和阴影
- 字体：现代无衬线字体，标题使用等宽字体增强科技感
- 布局：左侧控制面板（固定宽度），右侧3D画布（自适应铺满）
- 图标：使用Unicode符号和简单几何形状，保持简洁
- 整体风格：赛博朋克/太空探索主题，深色背景配合发光效果

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页 | 3D画布 | 全屏Canvas，深色背景，支持鼠标交互 |
| 主页 | 控制面板 | 左侧固定面板，半透明玻璃效果，分组折叠展开 |
| 主页 | 统计面板 | 画布右下角，半透明显示，等宽字体 |
| 主页 | 导出按钮 | 底部工具栏，突出设计 |

### 4.3 响应式设计
- 桌面端优先设计
- 移动端自动调整控制面板为可折叠抽屉
- 触屏支持双指缩放和单指旋转

### 4.4 3D场景指引
- 环境：深色背景配合星空粒子效果（可选）
- 光照：环境光（AmbientLight）+ 点光源（PointLight），可独立开关
- 相机：PerspectiveCamera，初始距离5，支持OrbitControls拖拽
- 合成：几何体居中显示，地面反射平面在下方
- 交互：鼠标左键旋转视角，滚轮缩放，右键平移
- 后处理：可选Bloom泛光效果增强发光材质
- 性能：单几何体模式下60fps，多几何体模式下保持30fps以上
