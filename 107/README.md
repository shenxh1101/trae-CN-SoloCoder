# ✈️ 旅行行程规划工具

一个功能丰富的Python命令行旅行行程规划工具。

## 功能特性

### 1. 旅行计划管理
- 创建多个旅行计划，包含目的地、开始日期和结束日期
- 查看所有旅行计划的时间线（按开始日期排序）
- 编辑和删除旅行计划

### 2. 每日行程安排
- 为每个计划添加每日行程，包括时间、地点和备注
- 行程自动按日期和时间排序

### 3. 导出功能
- 导出为整洁的文本文件（适合打印）
- 导出为格式精美的PDF文件

### 4. 行李清单
- 通用行李模板
- 根据目的地气候自动推荐行李物品
- 支持自定义添加和删除物品

### 5. 预算管理
- 添加预算项（交通、住宿、餐饮等）
- 支持人民币(CNY)和美元(USD)
- 统计总预算和已花费金额
- 手动设置汇率进行换算

### 6. 天气查询
- 集成Open-Meteo免费天气API
- 查询目的地在旅行期间的天气预报

### 7. 行程分享
- 生成简洁版、普通版、详细版三种分享文本
- 适合复制到微信等聊天软件

### 8. JSON导入导出
- 导出单个旅行计划为JSON文件
- 从JSON文件导入旅行计划

### 9. 地图位置标记
- 生成百度地图和高德地图链接
- 显示目的地搜索链接和行程地点标记

## 安装

```bash
# 安装依赖
pip install -r requirements.txt
```

## 使用方法

```bash
# 运行程序
python travel_planner.py
```

### 主要操作

1. **查看时间线** - 查看所有旅行计划，按开始日期排序显示
2. **创建新计划** - 输入计划名称、目的地、日期，可选自动生成行李清单
3. **管理行程** - 添加/删除每日行程安排
4. **管理预算** - 添加预算项，标记已花费
5. **导出文件** - 导出为PDF或文本文件
6. **天气查询** - 查询旅行期间的天气预报
7. **生成分享文本** - 一键生成可分享的行程文本
8. **地图链接** - 获取目的地地图搜索链接

## 项目结构

```
├── travel_planner.py    # 主程序入口（CLI界面）
├── models.py            # 数据模型定义
├── travel_manager.py    # 旅行计划管理器
├── packing_list.py      # 行李清单生成器
├── exporter.py          # PDF/文本导出器
├── weather_api.py       # 天气API集成
├── share_generator.py   # 行程分享文本生成
├── map_marker.py        # 地图链接生成
├── requirements.txt     # 依赖包列表
└── README.md            # 说明文档
```

## 数据存储

所有旅行计划数据默认保存在 `travel_plans.json` 文件中。
