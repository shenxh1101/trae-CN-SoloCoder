# 3D分子结构可视化 - 功能演示与测试报告

## 项目概述

基于Three.js的3D分子结构可视化网页应用，支持分子模型展示、交互操作、测量分析和数据导入导出。

## 技术实现详情

### 电子云Shader实现

```
顶点着色器:
- 传递UV、法线、位置到片元着色器

片元着色器:
- 菲涅尔效应: pow(1.0 - abs(dot(normal, view)), 2.0)
- 噪声函数: fract(sin(dot(position, seed)) * 43758.5453)
- 脉冲动画: sin(time * 2.0 + distance * 5.0)
- 透明度: 菲涅尔 * 0.8 + 脉冲 * 0.2, 限制在0~0.5
```

### 偶极矩计算逻辑

```
1. 遍历所有化学键
2. 计算两端原子电负性差
3. 如果差值 > 0.01:
   - 计算化学键方向向量
   - 归一化方向向量
   - 键偶极 = 电负性差 × 键序
4. 累加所有键偶极向量
5. 归一化得到总偶极矩方向
```

电负性数据(Pauling标度):
- H: 2.20, O: 3.44, C: 2.55, N: 3.04, S: 2.58, P: 2.19

### 键长测量流程

```
1. 用户点击"开始测量"按钮
2. 进入测量模式(isMeasuring = true)
3. 点击第一个原子:
   - 添加黄色高亮环
   - 添加发光效果
   - selectedAtoms = [atom1]
4. 点击第二个原子:
   - 计算两原子间距离
   - 显示黄色连接线
   - 显示距离标签(Å单位)
   - 退出测量模式
5. 点击"清除"按钮可重置测量
```

## 预置分子数据

### 水分子 (H₂O)
- 原子: 1个氧(O) + 2个氢(H)
- 键角: 104.5°
- 键长: O-H = 0.96 Å
- 偶极矩: 有极性，指向氧原子

### 二氧化碳 (CO₂)
- 原子: 1个碳(C) + 2个氧(O)
- 结构: 直线型
- 键长: C=O = 1.16 Å
- 偶极矩: 零(对称抵消)

### 甲烷 (CH₄)
- 原子: 1个碳(C) + 4个氢(H)
- 结构: 正四面体
- 键长: C-H = 1.09 Å
- 偶极矩: 零(对称抵消)
