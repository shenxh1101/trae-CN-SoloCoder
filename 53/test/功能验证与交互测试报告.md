### 2. 偶极矩计算逻辑验证

**实现位置**: [helpers.ts](file:///Users/mac/code/solo%20coder/53/src/utils/helpers.ts#L37-L91)

**电负性数据 (Pauling标度)**:
| 元素 | 电负性 |
|------|--------|
| H | 2.20 |
| C | 2.55 |
| N | 3.04 |
| O | 3.44 |
| S | 2.58 |
| P | 2.19 |

**计算算法**:
1. 遍历所有化学键
2. 计算两端原子电负性差
3. 若差值 > 0.01，计算键偶极向量
4. 归一化化学键方向
5. 键偶极大小 = 电负性差 × 键序
6. 累加所有键偶极向量
7. 归一化得到总偶极矩方向

**验证结果 (水分子 H₂O)**:
- ✅ O-H 电负性差: 3.44 - 2.20 = 1.24
- ✅ 两个O-H键偶极向量叠加
- ✅ 偶极矩方向指向氧原子
- ✅ 与分子实际极性一致

**验证结果 (二氧化碳 CO₂)**:
- ✅ 两个C=O键对称分布
- ✅ 偶极矩相互抵消
- ✅ 总偶极矩为零
- ✅ 非极性分子正确

**导出代码**:
```typescript
export function exportPNG(renderer: THREE.WebGLRenderer, filename: string): void {
  const dataURL = renderer.domElement.toDataURL('image/png');
  const link = document.createElement('a');
  link.download = filename;
  link.href = dataURL;
  link.click();
}
```
