# 股票模拟交易系统

一个功能完整的基于Python命令行的股票模拟交易工具，支持实时价格波动、买卖交易、止损止盈、多账户管理等功能。

## 功能特性

### 核心功能
- ✅ **10支预设股票** - 包含贵州茅台、五粮液、宁德时代、比亚迪等热门股票
- ✅ **实时价格波动** - 每5秒自动随机更新股票价格
- ✅ **模拟交易** - 支持买入、卖出股票，数量为100股整数倍
- ✅ **持仓管理** - 查看持仓明细、成本价、当前价、盈亏百分比
- ✅ **交易记录** - 完整记录所有买卖交易，包含时间、价格、数量、盈亏
- ✅ **止损止盈** - 设置自动止损止盈线，达到条件自动卖出
- ✅ **资产曲线** - 终端图表展示总资产历史变化趋势
- ✅ **多账户管理** - 创建多个独立账户，独立操作互不影响
- ✅ **日历热力图** - 每日资产快照，用颜色直观展示盈亏
- ✅ **分红送股** - 预设股票分红计划，自动计算分红
- ✅ **数据导出** - 支持导出交易记录、持仓、资产历史为CSV
- ✅ **手续费模拟** - 可设置佣金比例和最低手续费
- ✅ **账户重置** - 一键重置账户到初始状态

## 安装与运行

### 环境要求
- Python 3.8+
- 无需额外依赖（所有功能使用标准库实现）

### 运行程序
```bash
python3 main.py
```

### 运行测试
```bash
python3 test_system.py
```

## 使用说明

### 主菜单
```
【主菜单】
 1. 查看股票行情
 2. 查看持仓明细
 3. 买入股票
 4. 卖出股票
 5. 查看交易记录
 6. 设置止损止盈
 7. 查看资产曲线
 8. 查看日历热力图
 9. 账户管理
10. 导出数据
11. 手续费设置
12. 重置账户
 0. 退出系统
```

### 交易规则
- 初始资金：10万元
- 买入/卖出数量：必须为100的整数倍
- 手续费：默认0.03%，最低5元
- 价格更新：每5秒随机波动

### 止损止盈
- 止损线：当亏损达到设定百分比时自动卖出
- 止盈线：当盈利达到设定百分比时自动卖出
- 可在持仓中单独设置每支股票的止损止盈

### 数据存储
- 账户数据：`data/accounts/` 目录下，JSON格式
- 导出数据：`data/exports/` 目录下，CSV格式

## 核心模块说明

### models.py
定义了核心数据类：
- `Stock` - 股票信息
- `Position` - 持仓信息
- `TradeRecord` - 交易记录
- `Dividend` - 分红信息
- `Account` - 账户信息（支持序列化/反序列化）

### stock_engine.py
- 管理股票列表和价格
- 每5秒随机更新价格（波动率可配置）
- 管理分红事件，自动处理分红送股

### trading_engine.py
- 执行买入/卖出操作
- 计算手续费和盈亏
- 监控止损止盈条件
- 计算总资产和持仓明细

### visualization.py
- 终端字符图表展示资产曲线
- 日历热力图展示每日盈亏
- 单支股票价格走势图

## 特色功能

### 资产曲线
使用终端字符绘制资产变化趋势，支持最多50个数据点：
```
资产曲线 - 默认账户
============================================================
  101250 │          ██████
  101000 │        ██      █
  100750 │      ██        ██
  100500 │    ██            █
  100250 │   █              █
  100000 │ ██                █
   99750 │█
```

### 日历热力图
使用背景颜色直观展示每日盈亏情况：
- 深红色：亏损 > 10%
- 红色：亏损 5% ~ 10%
- 粉色：亏损 0% ~ 5%
- 浅绿：盈利 0% ~ 5%
- 绿色：盈利 5% ~ 10%
- 深绿：盈利 > 10%

### 自动止损止盈
在后台线程中监控持仓，当价格达到止损/止盈线时自动执行卖出操作，并在界面上显示提示信息。

## 开发说明

- 代码模块化设计，易于扩展新功能
