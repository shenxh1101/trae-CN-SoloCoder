## 创建的文件清单

### 1. `src/main/auto-discover.ts` - 邮箱自动发现服务
- 支持40+已知邮箱服务商配置（Gmail、Outlook、QQ、163、126、Yahoo、iCloud等）
- 多级发现策略：已知服务商匹配 → DNS SRV记录查询 → Microsoft Autodiscover XML/RPC → 智能猜测
- 核心方法：`discover(email: string, password: string)`

### 2. `src/main/security/tracker-blocker.ts` - 防追踪服务
- 检测并移除邮件中的追踪像素、web beacons
- 检测模式：100+追踪URL模式、50+追踪主机域名、150+追踪查询参数
- 支持base64内嵌图片尺寸检测
- 发件时自动移除URL追踪参数
- 核心方法：`detectAndRemoveTracking()`, `cleanTrackingParams()`, `processOutgoingEmail()`

### 3. `src/main/security/gpg-service.ts` - GPG加密服务
- 使用openpgp库实现完整的OpenPGP功能

### ✅ 已实现的核心功能

#### 1. **多邮箱账户管理**
- 支持 Gmail、Outlook、QQ邮箱、163、126、Yahoo、iCloud 等 40+ 主流服务商
- 自动配置发现（DNS SRV记录、Microsoft Autodiscover、智能猜测）
- 手动服务器设置（IMAP/SMTP 主机、端口、加密方式）
- 多账户独立管理，支持不同同步策略

#### 2. **IMAP/SMTP 协议实现**
- 使用 Node.js `net`/`tls` 模块原生实现
- 支持 SSL/TLS 和 STARTTLS 安全连接
- 支持 LOGIN/PLAIN 认证方式
- IMAP 命令：LIST、SELECT、FETCH、STORE、COPY、MOVE、APPEND、SEARCH、EXPUNGE
- IMAP IDLE 扩展（实时邮件推送）
- SMTP 扩展：DSN、PIPELINING、8BITMIME

#### 3. **邮件收发功能**
- 纯文本、HTML、Markdown 三种编辑模式
- 富文本编辑器（格式化工具栏）
- Markdown 实时预览
- 多附件支持，拖拽上传
- 自动签名插入
- 邮件模板快速插入

#### 4. **完整的 IMAP 同步**
- 文件夹同步（包括嵌套文件夹）
- 邮件状态同步（已读/未读、已回复、已转发、红旗标记）
- 增量同步和全量同步
- 按同步天数限制，减少流量
- 附件大小限制配置

#### 5. **邮件搜索功能**
- 全文搜索（主题、正文、发件人）
- 多条件筛选：发件人、收件人、时间范围、有无附件、标签、已读/未读、星标
- 搜索结果关键词高亮
- 最近搜索历史

#### 6. **过滤规则引擎**
- 8 种条件字段：发件人、收件人、主题、正文、日期、大小、附件、标签
- 11 种操作符：等于、包含、开头、结尾、大于、小于等
- 13 种动作：移动、复制、删除、标记、加标签、转发、自动回复等
- 规则优先级排序
- 条件组合（AND/OR）
- 规则测试和手动运行

#### 7. **标签系统**
- 多级标签（父子关系）
- 20 种预设颜色可选
- 快速筛选和按标签聚合
- 排序调整

#### 8. **邮件会话线程**
- 基于 References 和 In-Reply-To 自动聚合
- 线程视图和列表视图切换
- 显示所有参与者
- 未读计数统计

#### 9. **离线缓存**
- 邮件正文和附件默认下载到本地
- 可配置不同账户的同步天数
- 可配置附件大小限制
- SQLite 本地存储，访问快速

#### 10. **签名管理**
- 每个账户可设置不同的 HTML 签名
- 可视化和 HTML 双模式编辑
- 撰写邮件时自动插入

#### 11. **邮件模板**
- 保存常用邮件内容为模板
- 支持变量插入
- 一键插入新邮件

#### 12. **防追踪功能**
- 自动检测并移除邮件中的追踪像素
- 100+ 追踪 URL 模式库
- 发件时自动移除 URL 追踪参数

#### 13. **GPG 加密**
- 使用 OpenPGP.js 实现完整的 OpenPGP 功能
- 密钥管理：导入、导出、删除
- 邮件内容加密、解密
- 数字签名和验证
- AES-256 加密，SHA-512 哈希

#### 14. **自动备份**
- 定期备份整个 SQLite 数据库
- 可选是否包含附件文件夹
- 压缩备份（tar.gz）
- 保留策略（自动清理旧备份）
- 手动触发备份和恢复

#### 15. **插件机制**
- 基于 Node.js `vm` 模块的安全沙箱
- 14 种细粒度权限控制
- 插件 API：存储、通知、事件、邮件操作
- 生命周期管理（onLoad, onUnload）
- 示例插件已提供
