## 1. 产品概述

网页版节奏敲击游戏，类似跳舞机玩法。玩家在音符方块到达判定线时按下对应方向键获得分数，支持多首内置歌曲和自定义歌曲。

- **主要目的：提供娱乐性的音乐节奏游戏体验
- **目标用户**：音乐游戏爱好者，休闲玩家
- **市场价值**：轻量级网页游戏，无需下载，即开即玩

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|-----------|-----------|
| 普通玩家 | 无需注册 | 游玩所有歌曲，编辑自定义歌曲，查看最高分 |

### 2.2 功能模块
1. **主菜单页面**：歌曲选择，游戏设置
2. **游戏页面**：音符下落，按键判定，分数计算，血条显示
3. **结算页面**：得分展示，评级显示
4. **自定义歌曲页面**：音频上传，节奏点编辑

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-----------|-------------|
| 主菜单 | 歌曲列表 | 显示内置歌曲列表，显示每首歌最高分 |
| 主菜单 | 设置选项 | 开始游戏，自定义歌曲入口 |
| 游戏页面 | 游戏区域 | 4轨道音符下落，判定线显示 |
| 游戏页面 | 状态显示 | 实时分数，连击数，血条进度 |
| 游戏页面 | 判定反馈 | Perfect/Good/Miss显示 |
| 结算页面 | 结果展示 | 最终得分，评级，最高分对比 |
| 自定义歌曲 | 音频上传 | 支持上传本地音频文件 |
| 自定义歌曲 | 节奏编辑 | 可视化节奏点时间轴编辑 |

## 3. 核心流程

用户选择歌曲 → 进入游戏 → 音符随BPM同步下落 → 玩家按键判定 → 计分/扣血 → 歌曲结束/血条空 → 显示结算结果

```mermaid
flowchart LR
    A["选择歌曲"] --> B["开始游戏"]
    B --> C["音符同步下落"]
    C --> D{"按键判定"]
    D -->|Perfect/Good| E["加分+连击"]
    D -->|Miss| F["扣血"]
    E --> G{"歌曲结束?"}
    F --> H{"血条为空?"}
    H -->|是| I["游戏结束"]
    G -->|是| J["显示结算"]
    G -->|否| C
    H -->|否| C
    I --> J
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深色背景配合霓虹色彩（青、粉、紫渐变）
- **按钮风格**：圆角霓虹边框，悬停发光效果
- **字体**：Orbitron（显示字体）+ Noto Sans SC（正文）
- **布局风格**：游戏区域居中，信息面板分布两侧
- **图标风格**：霓虹发光风格箭头，动感科技感

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|----------|
| 主菜单 | 歌曲卡片 | 渐变背景，歌曲名称，BPM，最高分徽章 |
| 游戏页面 | 判定线 | 霓虹发光效果，4轨道 |
| 游戏页面 | 音符方块 | 箭头图标，发光边框 |
| 游戏页面 | 血条 | 渐变色进度条，危险时红色闪烁 |
| 结算页面 | 评级展示 | 大号评级文字，分数动画 |

### 4.3 响应式
- Desktop-first，移动端自适应布局
- 移动端支持触屏虚拟按键

### 4.4 动画效果
- 音符下落平滑动画
- 按键判定闪光效果
- 连击数递增动画
- 血条变化过渡动画
- 结算页面评级出现动画
