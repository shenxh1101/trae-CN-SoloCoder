## 1. 产品概述

基于Flask的轻量级网络书签管理服务，无需数据库，使用JSON文件存储数据。为个人用户提供一站式书签管理体验，包括分类组织、标签筛选、健康检测、点击统计、导入导出及加密备份等完整功能。

- 目标用户：需要高效管理大量网络书签的个人用户
- 核心价值：零依赖数据库、浏览器书签兼容、自动健康检测、加密备份

## 2. 核心功能

### 2.1 用户角色
不涉及多用户角色，为单用户本地部署应用。

### 2.2 功能模块
1. **书签管理页**：书签列表、添加/编辑/删除书签、搜索、排序、分类分组显示
2. **分类管理页**：分类的增删改、删除分类时迁移书签
3. **标签筛选**：按标签过滤书签、热门标签展示
4. **健康检测**：自动HEAD请求检测、失效标记、失效书签列表
5. **统计排行**：点击次数统计、热门书签排行
6. **导入导出**：HTML书签导入导出、浏览器书签兼容导入、加密JSON备份恢复
7. **分享页面**：为分类生成只读HTML分享页
8. **主题切换**：暗色/亮色主题

## 3. 核心流程

### 3.1 书签管理主流程
用户打开应用 → 查看按分类分组的书签列表 → 可搜索/筛选/排序 → 点击书签访问（计数+1） → 可添加/编辑/删除书签

### 3.2 健康检测流程
定时触发或手动触发 → 对所有书签发送HEAD请求 → 根据状态码标记正常/失效 → 失效书签展示在专门列表 → 用户可清理失效书签

### 3.3 导入导出流程
- 导出：选择导出格式（HTML/加密JSON）→ 生成文件 → 下载
- 导入：选择文件 → 解析（HTML书签/加密JSON）→ 与现有数据合并 → 保存

### 3.4 分类删除流程
用户选择删除分类 → 弹出确认 → 选择迁移目标分类或删除书签 → 执行操作

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：琥珀色（Amber）作为主色调，搭配深灰色背景（暗色模式）/ 暖白色背景（亮色模式）
- **按钮风格**：圆角8px，柔和阴影，hover时微妙提升
- **字体**：正文使用 "Noto Sans SC"，标题使用 "Playfair Display"
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式书签展示
- **图标风格**：使用Lucide图标库，线条风格，2px粗细

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 书签列表页 | 侧边导航 | 分类列表、标签云、快速链接，固定左侧 |
| 书签列表页 | 顶部工具栏 | 搜索框、排序下拉、主题切换、健康检测按钮 |
| 书签列表页 | 书签卡片网格 | 标题、URL、分类标签、标签徽章、点击次数、状态指示灯 |
| 书签列表页 | 热门书签侧栏 | 排行列表，显示排名、标题、点击次数 |
| 书签列表页 | 失效书签面板 | 警告色卡片列表，快捷删除按钮 |
| 分类管理页 | 分类卡片 | 分类名称、书签计数、编辑/删除按钮 |
| 导入导出页 | 操作卡片 | 文件上传区、格式选择、进度条 |
| 分享页面 | 独立只读页 | 分类标题、书签列表，简洁美观 |

### 4.3 响应式设计
- 桌面优先设计，侧边导航在移动端折叠为汉堡菜单
- 书签卡片网格自适应：4列→3列→2列→1列
- 触摸优化：卡片点击区域≥44px

### 4.4 主题系统
- 亮色主题：暖白背景(#FAFAF5)、深色文字、琥珀色强调
- 暗色主题：深灰背景(#1A1A2E)、浅色文字、琥珀色强调
- 使用CSS变量统一管理，切换时平滑过渡
