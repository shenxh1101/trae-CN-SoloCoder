# 图像批量处理工具 - 界面说明

## 🚀 启动方式

```bash
cd "/Users/mac/code/solo coder/29"
python3 main.py
```

## 📺 界面总体布局

```
┌─────────────────────────────────────────────────────────────────────┐
│  [文件列表]  │  [  预览区域: 原图 | 处理后  ]  │  [功能选项卡]    │
│              │  [ 进度条 | 处理日志 ]         │                    │
```

---

## 📁 左侧面板 - 文件列表

| 组件 | 功能 |
|------|------|
| **添加文件** | 批量选择多个图片文件（支持 JPG/PNG/BMP/WEBP） |
| **添加文件夹** | 递归扫描文件夹内所有图片，自动过滤非图片文件 |
| **移除** | 从列表中移除选中的文件 |
| **清空** | 清空文件列表 |
| **文件列表框** | 显示已添加的图片文件名，点击可预览 |
| **输出目录** | 设置处理后图片的保存目录 |

---

## 👀 中间面板 - 预览区域

```
┌──────────────────────────────────────────────────────────┐
│ [原图] [应用预览] [重置] [添加到任务队列]    尺寸: WxH │
├───────────────────────────────────┬──────────────────────┤
│                                   │                      │
│            原图画布               │     处理后画布        │
│       (显示原始图片)             │   (显示处理效果)      │
│                                   │                      │
└───────────────────────────────────┴──────────────────────┘
```

**使用方式：**
1. 点击左侧文件列表中的图片即可加载预览
2. 在右侧设置好处理参数后，点击「预览效果」按钮
3. 左右对比查看处理前后的效果
4. 满意后点击「添加到任务队列」

## ✅ 已修复的Bug

1. **尺寸调整选项卡崩溃**：`update_resize_mode()` 中 `before` 参数传入 `BooleanVar` 而非 widget → 改为保存 Checkbutton 引用
2. **水印选项卡崩溃**：`update_watermark_type()` 中 `after` 参数使用不可靠的 `children` 列表 → 改为保存类型选择frame的引用
3. **选项卡无法访问**：`control_notebook` 是局部变量 → 改为实例属性 `self.control_notebook`
4. **颜色调整无实时预览**：滑动条变化时仅更新数值标签 → 添加 50ms 防抖的实时预览回调
